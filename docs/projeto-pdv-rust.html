Linha piloto do PDV

A segunda linha de caixa, mais leve, piloto Windows (v0.1.2). Convive com a linha madura; não a substitui.

Detalhe da linha piloto

Rust Tauri 2 React SQLite v0.1.2 Piloto Windows
Sem conflito de versões: ambos são PDVs Desktop. O Java usa o canal v3.2.2-free; esta linha usa release v0.1.2. O posicionamento V3 de negócio (PME, PIX Split 2027) aplica-se às duas.
PDV Desktop Java continua disponível: oferta madura multi-plataforma em pdv.caracore.com.br (Java · JavaFX). A iniciativa Rust + Tauri não substitui essa linha.

O que muda para você

É o mesmo caixa CaraCore PDV, com outra tecnologia por baixo: Rust para robustez e Tauri 2 para um programa Windows enxuto, com instalador em português. Comece no PDV local (um PC) e evolua para PDV na rede quando precisar.

Edição gratuita: até 100 vendas para testar na loja; condições na transparência rust-pdv.

  • Programa mais leve e startup rápido (Tauri 2)
  • Menos risco de falhas de memória (Rust)
  • Instaladores MSI/NSIS em português do Brasil
  • Operação offline com SQLite local
  • PIX com QR Code e confirmação no caixa

Detalhe opcional

Monorepo caracore-pdv-rust: crates Rust (backend/pdv-core), app Tauri 2, UI React, SQLite. Publicação via scripts Python com smoke de artefatos pt-BR e manifesto SHA256.

  • Oficina: caracore-pdv-rust
  • Loja: caracore-pdv-rust-releases — rust-pdv.caracore.com.br
  • Releases: artefatos da tag v0.1.2 em caracore-pdv-releases (não usar /releases/latest — latest daquele repo é o canal Java)
  • Linha Java: caracore-pdv — canal v3.2.2-free, oficina/loja separadas
  • Retomada: docs/contexto-rapido.md e docs/status.md na oficina

PDV local e PDV na rede

Local (um PC)

O padrão do piloto: SQLite em %APPDATA%\caracore-pdv\data\pdv.db. A loja vende mesmo sem internet. Setup na primeira abertura.

Na rede (vários caixas)

PostgreSQL é opcional para multi-caixa. A vitrine explica as duas modalidades; o download continua sendo o mesmo instalador Windows.

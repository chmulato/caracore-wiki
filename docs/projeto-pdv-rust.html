CaraCore PDV (Rust + Tauri)

PDV desktop — release v0.1.2, PDV local e rede, download em GitHub Releases, vitrine rust-pdv

Rust Tauri 2 React SQLite v0.1.2
Sem conflito de versões: ambos são PDVs Desktop. O Java usa o canal v3.2.2-free; esta linha Rust usa release v0.1.2. São faixas independentes do mesmo produto CaraCore PDV. O posicionamento V3 de negócio (PME, PIX Split 2027) aplica-se a ambas.
PDV Desktop Java continua disponível: oferta madura multi-plataforma em pdv.caracore.com.br (Java · JavaFX). A iniciativa Rust + Tauri não substitui essa linha.

Para leigos

É o mesmo caixa CaraCore PDV, com outra tecnologia por baixo: Rust para robustez e Tauri 2 para um programa Windows enxuto, com instalador em português. Comece no PDV local (um PC) e evolua para PDV na rede quando precisar.

Edição gratuita: até 100 vendas para testar na loja; condições e limites descritos na transparência rust-pdv. PIX com QR e confirmação no caixa.

O que Rust + Tauri trazem:

  • Programa mais leve e startup rápido (Tauri 2)
  • Menos risco de falhas de memória (Rust)
  • Instaladores MSI/NSIS em português do Brasil
  • Operação offline com SQLite local

Para estagiários

Monorepo caracore-pdv-rust: crates Rust, app Tauri 2, UI React, SQLite. Publicação via scripts Python com smoke de artefatos pt-BR e manifesto SHA256.

  • Loja: caracore-pdv-rust-releases — rust-pdv.caracore.com.br (vitrine + transparência)
  • Releases: caracore-rust-pdv-releases — v0.1.2 Windows
  • Linha Java: caracore-pdv — canal v3.2.2-free, oficina/loja separadas

Cara Core PDV v3 (Rust + Tauri)

Nova geração do caixa CaraCore — piloto Windows, instaladores em português do Brasil

Rust Tauri 2 React SQLite v0.1.0
Linha Java continua disponível: quem precisa de oferta madura multi-plataforma deve usar o PDV Desktop Selo Verde (Java · JavaFX).

Para leigos

O PDV v3 é o caixa CaraCore reescrito com tecnologia moderna (Rust), empacotado para Windows com instalador em português. Ideal para lojas piloto que querem testar a nova geração mantendo dados locais na máquina da loja.

  • Vendas, caixa, produtos e relatórios do dia
  • Operação offline para o balcão
  • NSIS, MSI pt-BR e ZIP portátil na release oficial

Para estagiários

Monorepo Rust com app desktop Tauri, frontend React e persistência SQLite. Publicação via scripts Python (tauri_bundle_windows.py, publish_release_delivery.py) com smoke de artefatos e manifesto SHA256.

  • Oficina: caracore-pdv-rust
  • Loja: caracore-pdv-rust-releases (GitHub Pages)
  • Release piloto: v0.1.0 — Windows x64 pt-BR

RU (Bioreator) — Sala Retrô 1991

Simulador de biorreator e balanço estequiométrico de massa

Java 21 JavaFX Maven SQLite Lançamento FREE (Roadmap): 18/06/2026
Bunker Acadêmico: Inspirado nas salas de aula de Engenharia Química e Hidrometalurgia de 1991 (UFPR), o simulador opera totalmente offline com uma interface nostálgica que emula a clássica calculadora HP-48SX no topo.

Para leigos

O simulador RU (Restaurante Universitário) permite simular a operação real de um tanque biológico, acompanhando o consumo de oxigênio, substratos e o crescimento de biomassa. O aluno explora conceitos clássicos de conservação de massa (Lei de Lavoisier) de forma visual e segura.

  • HP48SX funcional embutida no topo do painel
  • Gráficos em tempo real sobre a microvida e gases no biorreator
  • Modo local gratuito para fins educacionais e acadêmicos

Para estagiários

Trabalhe com Java 21 + JavaFX utilizando a API assíncrona baseada em Virtual Threads (Java Concurrency) para evitar travamento da interface durante simulações pesadas.

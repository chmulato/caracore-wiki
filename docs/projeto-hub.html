CaraCore Hub — encomendas, não “central telefônica”

O Hub é o sistema de gestão de encomendas para centros de distribuição: pedidos de vários marketplaces entram num só lugar, o estoque tem mapa e a retirada é conferida. A vitrine já está em hub.caracore.com.br. O lançamento público do instalador Windows é 06 de abril de 2027.

Honestidade de produto: o Hub não é o orquestrador interno da Cara Core nem uma API Python/Flask. Isso mistura o Hub com a Área 51. Também não está em oferta madura como o PDV Java: a oficina já tem a aplicação web (WAR/Tomcat); o que o calendário oficial chama de GA é o instalador Windows com SQLite local.

Para quem vende em vários canais

Quem vende no Mercado Livre, na Shopee e na Temu costuma abrir três painéis para ver o mesmo tipo de pedido. O Hub junta isso: o pedido chega, vai para uma posição no estoque e sai com conferência.

  • Centraliza pedidos de vários marketplaces
  • Mapa de estoque (rua, módulo, nível, caixa)
  • Inventário cíclico e etiquetas
  • Aviso no WhatsApp quando algo atrasa
  • Perfis ADMIN, SUPERVISOR e OPERADOR

O que o estagiário precisa saber

Uma oficina (caracore-hub, repositório privado) e uma loja (caracore-hub-releases). Stack da aplicação web: Jakarta EE 10 · WAR · Tomcat · JSP. PostgreSQL e Redis no ambiente atual da oficina; o destino público de 2027 é SQLite no computador do cliente.

  • Versão de referência na oficina: 2.1
  • Fases 1 a 5 da aplicação web marcadas como concluídas na oficina
  • Conectores vivos no código: Mercado Livre, Shopee, Temu
  • Há um envelope desktop (Electron + Tomcat embutido) no caminho do instalador
  • Licença proprietária; gratuito para pessoa física (estudo), conforme política Cara Core

O que já existe na oficina (não é GA pública)

Na oficina, a aplicação web de gestão de encomendas está em versão 2.1, com as cinco fases internas concluídas. Isso não significa que o cliente já baixa um instalador Windows ou que há um SaaS público do Hub.

Calendário oficial: o que o Eco Mundo e o AGENTS.md chamam de Garagem do Hub é o instalador Windows, não a inexistência de código. A analogia com o CSO Transportes vale: a oficina já tem produto; a oferta pública ainda não.

Dois tempos: WAR na oficina × instalador em 2027

Oficina hoje

Aplicação web empacotada como WAR, Tomcat, JSP/Bootstrap, PostgreSQL e Redis. Sobe com Docker na oficina. Não é desktop e não é o canal de download do cliente final.

Oferta pública

Instalador Windows com SQLite local (Bunker Digital), mesma soberania do PDV. A loja já antecipa essa história; o marco oficial é 06 de abril de 2027.

Tia Sócia é exemplo de negócio, não o nome do produto

O Programa Tias Sócias é uma proposta ilustrativa de última milha com impacto social, usada no pitch da loja. O produto que se instala e se opera continua se chamando CaraCore Hub. Números do pitch são ilustrativos.

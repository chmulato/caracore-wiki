Helianto Condominium

Administração de condomínio com dados na operação do cliente. Ainda em Garagem; calendário público 30/Dez/2027.

Java 25 Spring Boot 4 React PostgreSQL JasperReports BolePix Lançamento: 30/12/2027
Arquitetura Multi-Tenant Sólida: O Helianto opera com isolamento multilocatário no banco de dados relacional via tenant_id e filtro automático no Hibernate, protegendo os dados pessoais de cada morador com total rigor técnico.

O que muda para você

O Helianto é uma plataforma completa que facilita a vida do síndico e dos moradores. Ele gerencia as unidades, calcula o rateio das despesas (igualitário ou por fração ideal), cobra as cotas usando boleto integrado ao Pix (BolePix) para liquidação imediata e disponibiliza um extrato de despesas simples de entender.

  • Visualização clara dos boletos e cópia da linha digitável ou QR Pix
  • Breakdown detalhado do valor cobrado (taxa ordinária, fundo de obras, etc.)
  • Lembretes automáticos e controle de consentimentos de privacidade (LGPD)

Detalhe opcional

O monorepo do Helianto utiliza Spring Boot 4.0.6 + Java 25. Como estagiário, você trabalhará estendendo endpoints financeiros, ajustando o front-end responsivo React e lidando com o JasperReports para customização de PDF.

  • Oficina: caracore-helianto (Monorepo)
  • Loja: caracore-helianto-releases — helianto.caracore.com.br
  • Garantia de Qualidade: JaCoCo para cobertura de testes integrado ao Maven
  • Privacidade: PrivacyGuard (LGPD Shield) habilitado para mascaramento de PII em logs

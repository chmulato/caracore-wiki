BioReator 4.0

Simulador desktop de bateladas para estudo de bioprocessos. A Community 1.1.1 está publicada para Windows; os resultados são simulações didáticas, não medições de planta.

Java 25 JavaFX SQLite Windows Community 1.1.1
A Community 1.1.1 está publicada desde 13/10/2026. Consulte a loja do BioReator, os downloads, requisitos e hashes ou a release oficial no GitHub.

Community

  • Bradyrhizobium japonicum em batelada, com parâmetros didáticos configurados
  • Modelo de Monod com fatores de oxigênio, temperatura, pH, fase lag e decaimento celular
  • Gráficos ao vivo e distinção entre biomassa viável e total
  • Histórico local em SQLite e exportação CSV; a conversão para UFC/mL é uma estimativa configurada
  • Critérios de término: substrato esgotado, pico de OD, estagnação, tempo máximo ou parada manual
  • Tanque nominal configurável de 50 L a 10.000 L

A interface da Community 1.1.1

A aplicação roda localmente no Windows. O painel reúne condições da carga e variáveis calculadas; os gráficos acompanham a trajetória simulada e marcam o motivo do término.

O SQLite guarda o histórico no computador, mas esta edição não tem uma tela de consulta/listagem de lotes. Consulte a nota de privacidade e localização dos dados.

O que o simulador não representa

  • Não lê sondas de uma planta nem substitui controle experimental.
  • Os parâmetros do perfil são demonstrativos; não há validação experimental publicada para esta simulação.
  • Biomassa viável e UFC/mL são variáveis calculadas pelo modelo, não contagens laboratoriais.
  • O modelo não representa contaminação, identidade de cepa ou protocolo de produção.
  • Uma curva calculada não garante rendimento nem desempenho em escala industrial.

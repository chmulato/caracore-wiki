Ink Agenda

Gestão para estúdios de tatuagem no computador do estúdio. Versão estável v2.0.0 lançada em 26/Jun/2026 para Windows, macOS e Linux. Download na loja; documentação neste portal.

Java 25 JavaFX 21 SQLite v2.0.0 Licença proprietária
Código-fonte privado. Vitrine e instaladores: ink.caracore.com.br. Esta página substitui a antiga wiki da loja.

O que muda para você

Agenda de sessões, cadastro de clientes, receitas e despesas, saldo por período. Tudo no PC, sem depender de internet para funcionar.

  • Calendário e lista do dia (sem sobrepor horários)
  • Check de pagamento na lista do dia
  • Backup CSV GZIP com senha (soberania dos dados)

Detalhe opcional

Desktop nativo Java 25 + JavaFX 21.0.11 + SQLite. Oficina caracore-ink; loja caracore-ink-releases.

  • Build Maven; testes JUnit 5
  • Operação local (Bunker); internet só para baixar o instalador

Operação no estúdio

  • Conferir agenda do dia antes de abrir atendimento
  • Atualizar pagamento ao finalizar a sessão
  • Lançar despesas no mesmo dia
  • Backup diário no encerramento; cópia extra em mídia segura; retenção mínima de 7 dias úteis

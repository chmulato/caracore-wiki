CaraCore PDV — duas linhas, mesma filosofia

O CaraCore PDV é o caixa da loja. Existem duas linhas do mesmo produto: a oferta madura Java Free (backend Quarkus, operada pelo launcher no Edge na v4.0.0 e pelo navegador na versão anterior 3.2.12) e a linha piloto Rust (app nativo Windows). Nenhuma substitui a outra. Manuais estão neste portal; download fica na loja de cada linha.

Coexistência e versões: o PDV v4.0.0 foi lançado em 08/11/2026 e é a versão indicada para operar; o pacote saiu com os gates medidos (T032 17/17 e matriz 11/11, com a medição de desempenho, M11, não feita). A release v4.0.0 foi publicada em 06/11/2026 (ZIP portátil Windows x64, SHA-256 9557e0b1…d81eac, 176.613.179 B, assinada com duas chaves Ed25519), com lançamento em 08/11/2026. A versão anterior é a v3.2.12-free, última da linha 3.2.x, multiplataforma, com manutenção encerrada em 08/11/2026 e os pacotes ainda disponíveis; a build candidata v4.0.0-candidato-20261031 fica no histórico. Rust usa a release v0.1.4. São faixas independentes.

Linha madura

Linha atual · v4.0.0 · lançada em 08/11/2026 para Windows 10/11 x64, com launcher no Edge

Versão anterior · última da linha 3.2.x · canal v3.2.12-free, multiplataforma, com manutenção encerrada em 08/11/2026

O mesmo caixa CaraCore, com Rust no núcleo e Tauri 2 no shell. Começa no PDV local (um PC) e pode evoluir para PDV na rede. Download oficial no GitHub Releases.

O que muda para você e o detalhe opcional

O que muda para você

Os dois programas fazem o trabalho do caixa: registrar venda, fechar o dia e guardar os dados no computador da loja. A diferença é a tecnologia por baixo e o estágio da oferta. No Java Free não há PIX integrado (QR/gateway). Premium: assinatura mensal de R$ 79,90 com suporte, vendas e cadastros sem os tetos do Free (que vai até 100 vendas por mês), cálculo de CBS/IBS. NF-e/NFC-e está no roadmap, sem data. O PIX é feito pela maquininha do banco, fora do PDV. Saiba mais. O piloto Rust documenta PIX com QR nas próprias regras da edição gratuita.

  • Java — o caminho maduro: v4.0.0 no Windows 10/11 x64; a 3.2.12-free segue em Windows, Linux e macOS
  • Rust — piloto Windows, instalador em português, para avaliar a nova stack
  • Os dois operam offline por padrão (SQLite no PC da loja)
  • V3 de negócio vale para os dois: foco em PME

Detalhe opcional

Há duas oficinas e duas lojas. Manuais Java (trilhas, Wiki Fiscal, suporte) estão neste portal em pdv/. Transparência, formatos de instalador e piloto ficam na loja Rust; a ficha Rust está em projeto-pdv-rust.html.

  • Não afirmar que Rust “substitui” ou é “migração forçada” do Java
  • Não misturar números de versão (v3.2.x ≠ v0.1.x)
  • Download Rust oficial = o mesmo repo da loja (caracore-rust-pdv-releases/releases), não caracore-pdv-releases
  • CTAs novos nunca apontam para /delivery/

O programa escuta só neste computador, salvo configuração explícita. Roteiro: instalação com sucesso. Notas: 3.2.12-free. Manual e Wiki Fiscal: manual operacional Java.

Migrar da 3.2 para a 4

Suportada a partir da v4.0.0. A v4 atualiza o banco da linha 3.2.x no primeiro acesso (migrações 047 → 052, caminho medido 9/9 no pacote de 06/11/2026), desde que o arquivo esteja na pasta de dados dela antes da primeira abertura. Faça backup antes e mantenha a 3.2.12 instalada até conferir a operação; os pacotes da v3.2.12-free continuam disponíveis como versão anterior.
  • Faça backup da pasta de dados antes de qualquer teste ou migração.
  • Para migrar, copie o banco da 3.2 (%APPDATA%\caracore\caracore-pdv.db) para data\caracore-pdv.db na pasta da v4 antes da primeira abertura; a v4 atualiza o esquema sozinha e mantém vendas e histórico.
  • A v4 não tem a ação de estornar uma venda já finalizada: cancelar uma venda em aberto descarta a venda e não mexe no estoque. Na 3.2.12, o estorno de venda paga devolvia o estoque.
  • Mantenha a 3.2.12 instalada e o backup à mão até conferir a operação na v4.

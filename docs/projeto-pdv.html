CaraCore PDV — dois desktops, mesma filosofia

O CaraCore PDV é o caixa da loja, instalado no computador. Existem duas linhas desktop do mesmo produto: a oferta madura em Java e o piloto em Rust + Tauri. Nenhuma substitui a outra. A documentação operacional detalhada fica na wiki de cada loja.

Coexistência e versões: Java usa o canal v3.2.2-free; Rust usa a release v0.1.2. São faixas independentes. V3 é o posicionamento de negócio (PME e PIX Split 2027), não o número de release de nenhuma das linhas.

PDV Desktop (Java · JavaFX)

Oferta madura · canal v3.2.2-free

Caixa multi-plataforma para PME: vendas, PIX, comprovantes e operação local mesmo sem internet. Requisito do usuário: Java 25+ (Temurin recomendado).

  • Oficina: caracore-pdv
  • Loja: caracore-pdv-releases — pdv.caracore.com.br
  • Stack: Java 25 · Quarkus · JavaFX · SQLite
  • Windows · Linux · macOS
Wiki da loja Java Baixar v3.2.2-free

CaraCore PDV (Rust + Tauri 2)

Piloto Windows · release v0.1.2

O mesmo caixa CaraCore, com Rust no núcleo e Tauri 2 no shell. Começa no PDV local (um PC) e pode evoluir para PDV na rede. Download oficial no GitHub Releases.

  • Oficina: caracore-pdv-rust
  • Loja: caracore-pdv-rust-releases — rust-pdv.caracore.com.br
  • Stack: Rust · Tauri 2 · React · SQLite
  • Instaladores MSI/NSIS pt-BR + ZIP · SHA256
Resumo institucional GitHub tag v0.1.2

Para leigos e para estagiários

Para leigos

Os dois programas fazem o trabalho do caixa: registrar venda, receber PIX, fechar o dia e guardar os dados no computador da loja. A diferença é a tecnologia por baixo e o estágio da oferta.

  • Java — o caminho maduro, já em Windows, Linux e macOS
  • Rust — piloto Windows, instalador em português, para avaliar a nova stack
  • Os dois operam offline por padrão (SQLite no PC da loja)
  • V3 de negócio vale para os dois: PME e preparação para PIX Split 2027

Para estagiários

Há duas oficinas e duas lojas. Manuais de botão, Wiki Fiscal e trilhas de suporte ficam na loja Java. Transparência, formatos de instalador e piloto ficam na loja Rust.

  • Não afirmar que Rust “substitui” ou é “migração forçada” do Java
  • Não misturar números de versão (v3.2.x ≠ v0.1.x)
  • Download Rust oficial = GitHub Releases, não só a vitrine
  • CTAs novos nunca apontam para /delivery/

O que o PDV Rust entrega no piloto

Release v0.1.2, piloto Windows. Edição gratuita: até 100 vendas para testar — condições na transparência da loja.

No caixa

  • Checkout /vendas-v2 (carrinho, pagamento misto, scanner)
  • PIX com QR e confirmação no caixa
  • Abertura/fechamento de caixa e backup ao fechar turno
  • Estoque, clientes (LGPD), gestão e auditoria

Como instala e onde documenta

  • NSIS, MSI pt-BR ou ZIP — SHA256 na release
  • Download: loja Rust (tag GitHub v0.1.2, não latest)
  • Wiki da loja: modalidades local/rede, comparação e primeiros passos

CaraCore PDV — duas linhas desktop, mesma filosofia

A documentação técnica detalhada de cada linha fica na wiki da loja oficial. Ambos são aplicativos desktop instalados no computador da loja — esta página orienta qual linha consultar.

Coexistência: dois PDVs Desktop do mesmo CaraCore PDV — Java maduro (canal v3.1.2-free) e Rust + Tauri 2 (release v0.1.1, download em GitHub Releases). Stacks distintas, sem substituição.

PDV Desktop (Java · JavaFX)

Oferta madura · canal v3.1.2-free

Stack: Java 21, Quarkus, JavaFX, SQLite. Multi-plataforma, trilhas históricas (cliente, suporte, contador, sócio), Wiki Fiscal e planos Free/Premium.

Wiki da loja Java pdv.caracore.com.br

PDV Desktop (Rust + Tauri 2)

Piloto · release v0.1.1 · GitHub Releases

PDV desktop — qualidades de Rust (memória, performance) e Tauri 2 (shell enxuto, MSI/NSIS pt-BR). Mesmo posicionamento PME; stack distinta do Java.

Wiki da loja Rust Resumo institucional

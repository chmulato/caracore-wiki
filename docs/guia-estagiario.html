Configuração do Ambiente de Desenvolvimento

O que é "Ambiente de Desenvolvimento"?

É como preparar sua "oficina de trabalho" no computador. Assim como um carpinteiro precisa de suas ferramentas organizadas, você precisa dos programas certos instalados e configurados para trabalhar com nossos projetos.

1. Instalar Python

O que é: Python é a linguagem de programação principal que usamos.

Como instalar:

  1. Acesse o site oficial em https://www.python.org/ (fora da rede restrita, se necessário)
  2. Baixe Python 3.11 ou superior
  3. Execute o instalador
  4. ✅ Marque "Add Python to PATH"
Importante: Sempre marque "Add to PATH" na instalação!

2. Configurar Git

O que é: Git é como um "histórico de versões" do código.

Como configurar:

  1. Baixe em https://git-scm.com/ (fora da rede restrita, se necessário)
  2. Instale com configurações padrão
  3. Configure seu nome e email:
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

3. VS Code

O que é: Editor de código - onde você vai escrever e editar programas.

Extensões obrigatórias:

  • Python (Microsoft)
  • GitLens
  • Prettier
  • Live Server

4. GitHub

O que é: "Nuvem" onde guardamos todo o código dos projetos.

Primeiros passos:

  • Crie conta no GitHub: https://github.com/ (fora da rede restrita, se necessário)
  • Solicite acesso aos repositórios
  • Configure chave SSH (seu supervisor ajuda)

Entendendo Nossos Projetos

Aqui está uma explicação simplificada dos projetos com os quais você mais vai cruzar no início:

CaraCore PDV — duas linhas desktop

O que muda para você

É o caixa da loja. Existem dois programas: o Java maduro (Windows, Linux e macOS, canal v3.2.2-free) e o Rust piloto (Windows, v0.1.2). Os dois vendem no computador da loja, mesmo sem internet. Nenhum substitui o outro.

Detalhe opcional

Oficinas caracore-pdv (Java 25 · Quarkus · JavaFX) e caracore-pdv-rust (Rust · Tauri 2 · React). Lojas pdv.caracore.com.br e rust-pdv.caracore.com.br. Download Rust = GitHub Releases.

Java 25 Quarkus JavaFX Rust Tauri 2
Sua missão como estagiário: Não misturar versões (v3.2.x ≠ v0.1.x) e não dizer que Rust substitui Java. Hub: projeto-pdv.html.

CaraCore Hub — gestão de encomendas

O que muda para você

É o sistema do centro de distribuição: pedidos do Mercado Livre, da Shopee e da Temu entram numa fila só, o estoque tem mapa e a retirada é conferida. Não é a “central telefônica” da Cara Core. A vitrine já existe; o instalador Windows sai em 06/Abr/2027.

Detalhe opcional

Oficina caracore-hub (Jakarta EE 10 · WAR · Tomcat · JSP). PostgreSQL e Redis na web atual; SQLite no destino bunker. Python/Flask é Área 51, não Hub. Loja: hub.caracore.com.br.

Jakarta EE 10 Tomcat JSP PostgreSQL
Sua missão como estagiário: Não misturar Hub com Área 51. Hub: projeto-hub.html.

CaraCore CSO — Frotas e Transportes

O que muda para você

É o caderno da frota que deixa de ser planilha. No navegador a empresa cuida de veículos, combustível, oficina e equipe. O aplicativo de computador (2028) guarda os dados críticos na empresa. Não é rastreador GPS.

Detalhe opcional

Duas oficinas: caracore-cso-quarkus (Frotas Web, produção) e caracore-cso-transportes (desktop bunker). URL canónica: cso.caracore.com.br — não GitHub Pages.

Java 21 Quarkus Qute/HTMX PostgreSQL JavaFX
Sua missão como estagiário: Na Frotas, telas Qute/HTMX, i18n e relatórios. No Transportes, JavaFX/Vue e SQLite. Nunca sugerir GPS na copy. Hub: projeto-cso.html.

🎓 Circuito Ferradura - Produto educacional em evolução

O que muda para você

É uma proposta educacional da Cara Core para apresentar lógica, ábaco romano e primeiros passos em Python. O produto ainda está em evolução e depende de feedback real para amadurecer.

Detalhe opcional

Site educacional em HTML/CSS/JS com conteúdo Python introdutório, fases progressivas e pacotes locais para Windows/macOS. Foco em clareza, navegação simples e feedback de usuários.

HTML5 CSS3 JavaScript Bootstrap
Sua missão como estagiário: Melhorar textos, simplificar telas, testar os pacotes publicados e registrar feedback de pessoas interessadas.

Nossas Práticas de Desenvolvimento

Git Flow

Regra simples: Sempre crie uma nova branch para cada tarefa.

git checkout -b feature/minha-tarefa
Code Review

Regra simples: Todo código deve ser revisado por outro desenvolvedor antes de ir para produção.

Testes

Regra simples: Se você criou uma função, crie um teste para ela.

pytest test_minha_funcao.py

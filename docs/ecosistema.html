Mapa do ecossistema

Como a Cara Core se organiza: empresa → produto → oficina (onde o código vive) → loja (onde o cliente baixa e lê).

Eco Mundo é só o apelido interno desta página. Os três produtos-chave são o PDV (caixa), o CSO (frota) e o Hub (encomendas). O restante do portfólio não compete com esse núcleo.

Duas linhas de PDV convivem (nenhuma substitui a outra). CSO de frota já no ar; transportes no computador em 08/Nov/2028. Hub com vitrine hoje; instalador Windows em 06/Abr/2027.

Como ler este mapa

Não é um organograma técnico. É o caminho de uma ideia até o cliente.

1

Matriz

A empresa (www.caracore.com.br): o que vendemos, o que já existe, o que ainda não está em oferta aberta.

2

Produto

Oficina

Eco Mundo — Mapa do Ecossistema

Visualize como a Cara Core Informática se organiza: da matriz aos produtos, das oficinas às lojas.

Visão Geral do Ecossistema

Para Leigos

Imagine a Cara Core como uma árvore: o tronco é a empresa (matriz), os galhos são os produtos, as folhas são as oficinas onde cada produto é desenvolvido e os frutos são as lojas onde o cliente final encontra tudo pronto para usar.

Para Estagiários

O ecossistema segue quatro camadas. Cada produto nasce na matriz, é desenvolvido em uma oficina (repositório + ambiente de dev) e publicado em uma loja (subdomínio com wiki própria).

1. Matriz

Cara Core Informática

CNPJ 23.969.028/0001-37 — a empresa que mantém todo o ecossistema. Define estratégia, padrões de qualidade e roadmap dos produtos.

  • Governança: decisões de portfólio, precificação e licenciamento
  • Infraestrutura: domínio caracore.com.br, GitHub Organization, CI/CD
  • Pessoas: sócios, estagiários e colaboradores

2. Produtos

Cada produto resolve um problema diferente e possui identidade visual e técnica próprias.

PDV Desktop (Java)

Oferta madura multi-plataforma (canal v3.2.2-free): PIX, operação local, trilha fiscal. Java 25, Quarkus, JavaFX e SQLite. Convive com a linha Rust; não a substitui.

Hub PDV

CaraCore PDV

Linha desktop em Rust + Tauri 2, release v0.1.2, piloto Windows. Download no GitHub Releases. Coexiste com o CaraCore PDV Desktop (Java); nenhuma substitui a outra.

Detalhes

Ink Agenda

Gestão para estúdios de tatuagem com agenda, clientes e financeiro. Versão estável v2.0.0 lançada em 26/06/2026.

Detalhes

Minerador 4.0

Simulador ETE / hidrometalurgia para Ensino Médio e mineração (Ouro 4.0 R$ 29,90).

Detalhes

CaraCore Seed

Contador de licenças interno. Vitrine em seed.caracore.com.br; a aplicação não está em oferta pública.

Detalhes

Circuito Ferradura

Produto educacional em evolução para lógica, ábaco romano e Python. Uso pessoal gratuito; uso institucional mediante conversa e licença.

CaraCore Hub

Gestão de encomendas e marketplaces (ML, Shopee, Temu). Vitrine em hub.caracore.com.br; GA do instalador Windows em 06/Abr/2027. Oficina web 2.1 já existe — não é Flask.

Helianto Condominium

Sistema de administração condominial com soberania de dados, multi-tenancy e motor financeiro auditável. Garagem prevista para Dez/2027.

Plataforma dual: Gestão de Frotas já no navegador (produção) e Gestão de Transportes no desktop (bunker, 08/11/2028). CSO não é rastreador GPS. Aplicação em cso.caracore.com.br.

CaraCore CSO

Gestão de Frotas (Web) e Gestão de Transportes (Desktop) — soberania operacional para logística

Quarkus Java 21 PostgreSQL JavaFX SQLite Frotas em produção Transportes 08/11/2028
Duas frentes, um produto: a Gestão de Frotas já opera no navegador em cso.caracore.com.br (captação, planos, frota e LGPD). A Gestão de Transportes é o bunker desktop (JavaFX + SQLite) para telemetria e backup local, com lançamento em 08 de novembro de 2028.

Para leigos

O CaraCore CSO é o centro logístico da operação. No dia a dia, a equipe usa o aplicativo web para veículos, motoristas, viagens, custos e planos. O desktop (quando chegar) guarda os dados críticos no computador da empresa e cuida do rastreamento pesado — mesmo se a internet falhar.

  • Gestão de frota no navegador (já disponível)
  • Planos FREE_3, P5, P10 e CORPORATE, com Pix e registro LGPD
  • Bunker local para telemetria e backup (trilha 2028)

Para estagiários

Não há uma oficina única caracore-cso. O produto vive em duas oficinas e a URL pública é a aplicação, não uma loja GitHub Pages.

  • Frotas (Web): oficina caracore-cso-quarkus — Quarkus, PostgreSQL, Qute/HTMX, i18n
  • Transportes (Desktop): oficina caracore-cso-transportes — JavaFX + SQLite, bunker offline
  • Aplicação canónica: cso.caracore.com.br
  • Releases: caracore-cso-releases não substitui a aplicação (sem vitrine de loja)

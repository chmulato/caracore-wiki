CaraCore CSO — duas frentes, um produto de logística

O CSO é o caderno da frota: a Gestão de Frotas já opera no navegador; a Gestão de Transportes chega no computador da empresa em 08 de novembro de 2028. A URL pública é a aplicação, não uma loja GitHub Pages. Não é GPS.

Honestidade de produto: o CSO que o cliente contrata hoje é gestão administrativa de frota (veículos, combustível, manutenção, equipe e relatórios). Não é rastreador GPS nem mapa ao vivo. O Virtual Tracker™ é um produto futuro, separado, previsto para 2028.

Gestão de Frotas (Web)

Em produção · cso.caracore.com.br

SaaS multi-tenant no navegador para PME que ainda usa planilha: cadastro de veículos, abastecimentos, manutenções, motoristas, viagens, relatórios e LGPD. Começa grátis com até 3 veículos.

  • Oficina: caracore-cso-quarkus
  • Stack: Java 21 · Quarkus · PostgreSQL 16 · Qute/HTMX
  • i18n: pt, en, es, it, de

O que muda para você e o detalhe opcional

O que muda para você

Pense no CSO como o caderno da frota que deixa de ser planilha. No dia a dia a equipe entra no site, registra veículos, combustível, oficina, motoristas e viagens, e o gestor vê relatórios. Cada empresa vê só os próprios dados.

  • Começar grátis (até 3 veículos), sem cartão no cadastro
  • Planos pagos em reais, com Pix no Brasil
  • Perfis claros: quem administra, quem gestiona, quem opera
  • O desktop de 2028 guarda a operação crítica na empresa, mesmo se a nuvem falhar

Detalhe opcional

Não existe uma oficina única caracore-cso. São duas oficinas e a URL canónica é a aplicação web. caracore-cso-releases não substitui o produto no ar.

  • Frotas: SSR Qute + HTMX, sessão opaca no Postgres, RBAC, Flyway, multi-tenant
  • Transportes: API REST + SPA Vue + cliente JavaFX, SQLite local, JWT na trilha desktop
  • Regra de copy: não sugerir GPS, mapa em tempo real ou rastreador na UI nem na wiki
  • Credenciais de demo: só no README da oficina, e só no banco local — nunca em produção

O que a Gestão de Frotas já faz

Momento atual (produção em cso.caracore.com.br): o cliente organiza a frota e os custos. Completar km/L, pneus, documentos do veículo e custo por km entra depois, no mesmo produto, sem taxa extra.

Cobrança sempre em reais. No Brasil, Pix avulso; fora, transferência internacional equivalente. A operação libera o plano após o comprovante — não é PIX recorrente automático.

Quem acessa o quê

  • ADMIN — administra a empresa: usuários, convites, frota, relatórios e auditoria LGPD
  • GESTOR — opera a frota e vê relatórios; não gerencia usuários nem convites
  • ENTREGADOR — telas operacionais do dia a dia, sem menu admin nem relatórios

Todos entram pelo mesmo /login. O ADMIN define o perfil ao cadastrar. Há um operador interno da Cara Core (área discreta) que não mistura sessão com a frota do cliente.

Gestão de Transportes — o bunker de 2028

Em desenvolvimento (Garagem). Lançamento previsto: 08 de novembro de 2028. Não há download público nem vitrine GitHub Pages. A URL de referência continua sendo cso.caracore.com.br.

O que muda para você

É o CSO que mora no computador da empresa. Serve para quem precisa continuar operando entregas, equipe e clientes mesmo com internet instável, e para guardar uma cópia soberana dos dados críticos.

  • Entregas, entregadores, clientes, equipes e tabelas de preço
  • Banco local (SQLite) — o dado não depende só da nuvem
  • Acoplado à Gestão de Frotas; não a substitui

Detalhe opcional

Oficina caracore-cso-transportes: API REST Quarkus com SQLite, SPA Vue 3 e cliente JavaFX 21 em cs-desktop-fx/. A trilha soberana segue o Protocolo Amarelinha (Geometria → Dinâmica → Sombra → Massa → Céu).

  • Persistência local em SQLite; Flyway nas migrações
  • Autenticação JWT na API da oficina; JavaFX consome a API
  • Papel: bunker e roteamento de telemetria pesada — GPS/mapa ficam no Virtual Tracker™ (produto separado, 2028)

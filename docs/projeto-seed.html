Cara Core Seed

Aplicativo desktop local para cadastrar clientes e administrar licenças de software. O piloto público é gratuito e licenciado sob MIT. A pré-release candidata Windows 0.1.5 está disponível para avaliação; a 0.1.4 permanece como release estável anterior. A homologação independente da candidata está pendente.

Pré-release candidata 0.1.5 Electron · Java 25 SQLite Windows x64 MIT · gratuito
A pré-release candidata 0.1.5 está publicada para avaliação. Instalador Windows x64: 216.466.586 bytes; SHA-256: e449ca2cee74fda135ac098d2333fe674c2c476773a7d4adb60bc016a767db16. A candidata corrige problemas de segurança e robustez, mas homologação independente continua pendente; não a considere homologada nem pronta para produção. A versão estável anterior é a 0.1.4; a 0.1.3 foi substituída e não deve ser usada. Consulte a página de distribuição para baixar o instalador e conferir o checksum.

O que o piloto faz

Permite manter cadastros de clientes, criar e administrar licenças, acompanhar validade e limites, validar licenças assinadas e consultar eventos de auditoria e alertas. Registros de heartbeat são locais; não existe painel de monitoramento remoto.

  • Banco SQLite guardado no perfil local do usuário
  • Aplicação desktop Electron com backend Java 25 e Tomcat embutido
  • A tela de administração abre neste computador; não é um painel hospedado na nuvem nem fica disponível para outros computadores da rede
  • Operações administrativas pedem login; integrações de produtos usam um token separado por licença
  • A documentação técnica da API é servida pelo próprio aplicativo, sem dependência de CDN
  • Os sinais de atividade (heartbeats) são guardados localmente com horário do servidor; o horário enviado pelo produto integrado fica disponível para diagnosticar diferenças no relógio
  • A API fornece a assinatura e os dados exatos da licença para que o produto integrado possa verificar que não foram alterados
  • Sem serviço em nuvem, checkout ou pagamento real

Primeiro acesso e segurança

O primeiro acesso usa admin / admin e exige a troca da senha por uma nova de 12 a 128 caracteres, com confirmação. A janela inicial apresenta uma chave de recuperação: copie-a e guarde-a fora do computador. Se perder a senha, use a chave na tela de recuperação; não apague os arquivos de credenciais ou o banco.

O instalador publicado é unsigned. Não desative SmartScreen, Defender ou outras proteções do Windows.

Faça backup antes de atualizar e preserve o banco SQLite e as chaves de assinatura. A migração aditiva V8 mantém compatibilidade com bancos 0.1.3 e 0.1.4, preservando dados e chaves; licenças antigas podem precisar de emissão ou rotação do token de API para usar as rotas protegidas. A porta escolhida fica registrada em %APPDATA%\CaraCore Seed\server\server.port; consulte a interface Swagger local.

Guia rápido de uso

Este roteiro acompanha as opções disponíveis no aplicativo. Os nomes entre aspas são os textos dos menus e botões.

Clientes Licenças Assinaturas Backup e restauração Dúvidas comuns
  1. Abra o CaraCore Seed pelo atalho instalado. Na primeira entrada, use admin / admin, troque a senha quando solicitado e guarde a chave de recuperação fora deste computador. Nas próximas entradas, use a senha que você definiu.
  2. Encontre a área desejada na barra do aplicativo: Dashboard resume a operação; Clientes mantém os cadastros; Licenças emite e acompanha licenças; Assinaturas e Auditoria mostram os respectivos registros. Use Sair para encerrar a sessão.

Cadastrar um cliente

  1. Abra Clientes e escolha Novo Cliente.
  2. Preencha Razão Social, CNPJ, e-mail e telefone. Esses campos são obrigatórios; o CNPJ precisa ser válido. Nome fantasia, endereço, cidade, UF, CEP e observações podem complementar o cadastro.
  3. Confira o status e os dados e escolha Criar Cliente. Para localizar um registro depois, use a busca por razão social, nome fantasia ou CNPJ e o filtro de status.

O cadastro de cliente e os dados de centro pedidos no formulário de licença são etapas separadas. Confira se razão social e CNPJ correspondem nos dois lugares.

Criar uma licença

  1. Abra Licenças e escolha Nova licença.
  2. Informe Código do Centro, CNPJ válido, Plano, Razão Social, UF e Endereço. Complete contato e os limites/módulos que se aplicarem ao cliente.
  3. Revise os dados e escolha Gerar licença. A tela de detalhes mostra o identificador, plano, status, datas, limites e os dados registrados. Use esse identificador para localizar a licença na lista.
  4. Se o produto integrado precisar chamar a API do Seed, copie o token de integração mostrado na confirmação. Ele é exibido somente uma vez; guarde-o em local seguro. Esse token é diferente da assinatura digital da licença.

Mensalidade e moeda são campos de registro: o Seed não cobra, não processa pagamentos e não confirma recebimento.

Consultar e proteger licenças

  • Na lista, filtre por ID, CNPJ ou razão social. Abra Detalhes para conferir plano, status, emissão, vencimento e último heartbeat registrado.
  • Use Editar para revisar os dados permitidos pelo formulário.
  • Cancelar licença encerra a licença e não pode ser desfeito pela tela; confirme o ID antes da ação.
  • Gerar novo token de integração invalida o token anterior. Copie o novo token quando for exibido e atualize o sistema integrado; ele também só aparece uma vez.

O payload assinado identifica os dados da licença; o token autentica chamadas de integração. Não envie tokens, senhas ou chaves privadas em mensagens, URLs ou logs.

Registrar uma assinatura

  1. Abra Assinaturas e escolha Nova Assinatura. Primeiro, cadastre o cliente na área Clientes; o formulário exige um cliente existente.
  2. Selecione cliente e plano; informe valor mensal, início e término. Escolha o método, o status e, se desejar, a data de renovação e a opção de renovação automática.
  3. Revise e escolha Criar Assinatura. Use a lista para filtrar por status, consultar ou editar o registro.

Este registro é administrativo. Apesar de exibir métodos como PIX e cartão, o piloto não cobra, não processa pagamentos e não confirma transações; a renovação automática não deve ser entendida como cobrança automática.

Fazer ou restaurar backup

  1. No menu superior Dados, escolha Criar backup..., confirme o aviso e selecione onde salvar o arquivo .seedbackup.
  2. Guarde-o em local protegido e separado do computador. O backup contém banco, credenciais administrativas e chave privada de assinatura; ele não é criptografado.
  3. Para restaurar, abra Dados → Restaurar backup..., selecione o arquivo e confirme. A restauração substitui os dados atuais; o aplicativo guarda uma cópia local do estado anterior.
  4. Depois da restauração, entre com a senha administrativa que estava configurada quando o backup foi criado.

Mantenha mais de uma cópia protegida. Não compartilhe o backup em canais públicos: além dos dados, ele contém a chave que assina licenças.

Dúvidas comuns

O Seed é a licença que ativa os outros produtos?
Não. O Seed administra registros de clientes e licenças. Cada produto Cara Core mantém seu próprio aplicativo e banco; o Seed não centraliza esses dados.
Preciso de internet para abrir o Seed?
O console de administração funciona neste computador e não é um serviço na nuvem. Um produto integrado pode exigir internet conforme sua configuração e seus próprios requisitos.
O que faço se esquecer a senha?
Na tela de login, escolha Esqueci a senha — usar chave de recuperação e siga as instruções. A chave precisa ter sido guardada previamente; não apague nem substitua os arquivos do perfil.
Onde encontro o manual técnico da integração?
Com o Seed aberto, use a interface Swagger local. A porta é dinâmica; o arquivo %APPDATA%\CaraCore Seed\server\server.port informa qual porta foi escolhida. A documentação e seus recursos são servidos pelo próprio aplicativo, sem CDN.
Escopo desta etapa: piloto público para avaliação em Windows x64. Linux fica fora até haver build e smoke em runner Linux nativo. Além da homologação em perfil limpo, ainda faltam regressões manuais de licenças/assinatura/auditoria e de backup/restauração antes de considerar o produto pronto para produção.

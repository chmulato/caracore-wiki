Cara Core Seed

Aplicativo desktop local para cadastrar clientes e administrar licenças de software. O piloto público é gratuito e licenciado sob MIT. O candidato Windows 0.1.4 está disponível para avaliação, mas ainda aguarda homologação independente.

Piloto público Electron · Java 25 SQLite Windows x64 MIT · gratuito
O candidato `0.1.4` está publicado para avaliação. Instalador: 216.458.520 bytes; SHA-256: a01da8dbad7fdee2e9e59b1a99ed1be45b3f2e1d007d559cf289c6a606a30c2a. Esta versão corrige problemas de segurança e robustez, mas homologação independente e regressões manuais completas continuam pendentes. Não o considere homologado ou pronto para produção. Consulte a página de distribuição para baixar o instalador e verificar o checksum. A versão 0.1.3 foi substituída e não deve ser usada.

O que o piloto faz

Permite manter cadastros de clientes, criar e administrar licenças, acompanhar validade e limites, validar licenças assinadas e consultar eventos de auditoria e alertas. Registros de heartbeat são locais; não existe painel de monitoramento remoto.

  • Banco SQLite guardado no perfil local do usuário
  • Aplicação desktop Electron com backend Java 25 e Tomcat embutido
  • Servidor vinculado a 127.0.0.1, com porta local dinâmica e sem API exposta na rede local
  • API administrativa protegida por sessão ADMIN/CSRF; operações de integração protegidas por token por licença
  • Sem serviço em nuvem, checkout ou pagamento real

Primeiro acesso e segurança

O primeiro acesso usa admin / admin e exige a troca da senha por uma nova de 12 a 128 caracteres, com confirmação. A janela inicial apresenta uma chave de recuperação: copie-a e guarde-a fora do computador. Se perder a senha, use a chave na tela de recuperação; não apague os arquivos de credenciais ou o banco.

O instalador publicado é unsigned. Não desative SmartScreen, Defender ou outras proteções do Windows.

Faça backup antes de atualizar e preserve o banco SQLite e as chaves de assinatura. Licenças antigas podem precisar de emissão ou rotação do token de API para usar as rotas protegidas. A porta escolhida fica registrada em %APPDATA%\CaraCore Seed\server\server.port; consulte a interface Swagger local.

Escopo desta etapa: piloto público para avaliação em Windows x64. Linux fica fora até haver build e smoke em runner Linux nativo. Além da homologação em perfil limpo, ainda faltam regressões manuais de licenças/assinatura/auditoria e de backup/restauração antes de considerar o produto pronto para produção.

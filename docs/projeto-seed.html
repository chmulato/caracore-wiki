Cara Core Seed

Aplicativo desktop local para cadastrar clientes e administrar licenças de software. O piloto é gratuito, licenciado sob MIT e fechado por convite. O candidato Windows 0.1.3 ainda aguarda homologação independente; não há download público.

Piloto por convite Electron · Java 25 SQLite Windows x64 MIT · gratuito
O candidato `0.1.3` passou nos testes automatizados, mas ainda não foi homologado por outra IA nem instalado/avaliado em perfil limpo. Não há instalador público: solicitar convite é apenas uma manifestação de interesse e não garante participação. A loja seed.caracore.com.br informa o estado real do piloto.

O que o piloto faz

Permite manter cadastros de clientes, criar e administrar licenças, acompanhar validade e limites, validar licenças assinadas e consultar eventos de auditoria e alertas. Registros de heartbeat são locais; não existe painel de monitoramento remoto.

  • Banco SQLite guardado no perfil local do usuário
  • Aplicação desktop Electron com backend Java 25 e Tomcat embutido
  • Servidor vinculado a 127.0.0.1, sem API exposta na rede local
  • Sem serviço em nuvem, checkout ou pagamento real

Primeiro acesso e segurança

O primeiro acesso usa admin / admin e exige a troca da senha. A senha nova tem exatamente 8 caracteres e deve ser confirmada. A janela inicial apresenta uma chave de recuperação: copie-a e guarde-a fora do computador. Se perder a senha, use a chave na tela de recuperação; não apague os arquivos de credenciais ou o banco.

O instalador planejado é unsigned. Não desative SmartScreen, Defender ou outras proteções do Windows.

Escopo desta etapa: Windows x64. Linux fica fora até haver build e smoke em runner Linux nativo. Além da homologação em perfil limpo, ainda faltam regressões manuais de licenças/assinatura/auditoria e de backup/restauração antes de qualquer distribuição.

Cara Core Seed

Cadastre clientes e emita licenças digitais no próprio computador. O Seed é uma ferramenta local e complementar: cada produto Cara Core mantém seu aplicativo e seus dados.

Pré-release candidata 0.1.5 Windows x64 Gratuito · MIT
Versão para avaliação, ainda não homologada. A pré-release 0.1.5 é um candidato de teste, não uma versão declarada pronta para produção. O instalador não tem assinatura digital; confira o tamanho e o SHA-256 na página de download e não desative as proteções do Windows. A 0.1.4 é a versão estável anterior.

Primeiros passos

Da instalação à emissão de uma licença, siga estes passos e use os atalhos para consultar cada perfil.

Visão geral Clientes e licenças Administração Integrações Conceitos FAQ
  1. Instale: baixe o instalador Windows x64 na página oficial e confira tamanho e SHA-256 antes de executar.
  2. Entre: no primeiro início, use admin / admin, escolha uma senha nova (12 a 128 caracteres) e guarde a chave de recuperação fora do computador.
  3. Cadastre: em Clientes → Novo Cliente, informe razão social, CNPJ válido, e-mail e telefone.
  4. Emita: em Licenças → Nova licença, preencha os dados do centro e do plano e escolha Gerar licença.
  5. Conclua: se um produto for integrar com a API, copie o token exibido na confirmação e guarde-o com segurança. Ele aparece uma vez.

Resultado: cliente cadastrado e licença disponível para consulta. Para integrar um produto, configure nele o token e siga a documentação técnica.

O que o Seed faz — e o que não faz

Use o Seed para

  • Manter cadastros de clientes e licenças no computador local.
  • Consultar status, validade, limites e registros locais de atividade.
  • Emitir licenças assinadas para verificação pelo produto integrado.

Não use como

  • Cadastro centralizado: cada produto Cara Core mantém seu próprio aplicativo e banco.
  • Serviço em nuvem ou monitoramento remoto: o console e os registros de atividade são locais.
  • Sistema de cobrança: valores, meios de pagamento e renovações são registros administrativos, não transações.

Para quem opera o Seed

Cadastrar clientes

Objetivo: manter os dados de contato da organização.

Antes de começar: tenha razão social, CNPJ, e-mail e telefone.

  1. Abra Clientes e selecione Novo Cliente.
  2. Preencha os campos obrigatórios e, se necessário, complete nome fantasia e endereço.
  3. Confira os dados e escolha Criar Cliente. Depois, localize o cadastro pela busca ou pelo filtro de status.

Resultado: o cliente aparece na lista. O cadastro do cliente é separado dos dados do centro preenchidos ao emitir uma licença; confira razão social e CNPJ em ambos.

Criar e consultar licenças

Objetivo: registrar uma licença assinada com plano, validade e limites.

Antes de começar: reúna código do centro, CNPJ válido, razão social, UF e endereço.

  1. Abra Licenças → Nova licença, preencha os dados obrigatórios e escolha o plano.
  2. Revise validade e limites e selecione Gerar licença.
  3. Na lista, filtre por ID, CNPJ ou razão social. Abra Detalhes para conferir status, emissão, vencimento e atividade recente.

Resultado: a licença fica disponível para consulta pelo identificador. Cancelar uma licença encerra seu uso e não pode ser desfeito pela tela; confira o registro antes de confirmar.

Para administradores

Acesso e recuperação

  • Na primeira entrada, troque a senha temporária por uma senha de 12 a 128 caracteres.
  • Guarde a chave de recuperação fora do computador. Se esquecer a senha, use Esqueci a senha — usar chave de recuperação; não apague nem substitua os arquivos do perfil.
  • O instalador não tem assinatura digital. Confira o SHA-256 publicado e não desative SmartScreen, Defender ou outras proteções.

Assinaturas e auditoria

Em Assinaturas, registre cliente, plano, valor e datas para controle administrativo. Selecionar PIX, cartão ou renovação automática não inicia cobrança nem confirma pagamento. Em Auditoria, consulte os eventos administrativos disponíveis.

Backup e restauração

  1. No menu Dados, escolha Criar backup..., confirme e salve o arquivo .seedbackup em local protegido, separado do computador.
  2. Para restaurar, escolha Dados → Restaurar backup..., selecione o arquivo e confirme. A restauração substitui os dados atuais; uma cópia do estado anterior é guardada pelo aplicativo.
  3. Após restaurar, entre com a senha configurada quando o backup foi criado.

Proteja o backup: o arquivo não é criptografado e contém dados, credenciais e a chave privada que assina licenças. Restrinja o acesso e não o envie por canais públicos.

Para desenvolvedores e integrações

Configurar e verificar uma integração

  1. Em Licenças → Detalhes, copie o token de integração mostrado após a emissão. O token é exibido uma única vez.
  2. Configure-o no produto integrado usando o mecanismo seguro desse produto; não o coloque em URLs, código público ou logs.
  3. Com o Seed aberto, consulte a documentação Swagger local. A porta dinâmica está em %APPDATA%\CaraCore Seed\server\server.port.
  4. Use o signedPayload e o algoritmo informados pela API para verificar a assinatura. O token autentica chamadas; não substitui a assinatura.

A API local usa recursos servidos pelo próprio aplicativo, sem CDN. Heartbeats são registrados pelo horário UTC do servidor e preservam a hora informada pelo cliente para diagnóstico.

Dúvidas frequentes

Posso trocar o token de integração?

Sim. Em Licenças → Detalhes, gere um novo token. Isso invalida o anterior; atualize o produto integrado com o novo valor, exibido uma única vez.

O Seed funciona sem internet?

O console de administração é local. O produto integrado pode ter requisitos próprios de conexão; verifique a configuração dele.

Onde ficam os dados?

No perfil local de dados do aplicativo. Use Dados → Criar backup... para fazer uma cópia; não mova nem apague arquivos internos manualmente.

O backup contém chaves privadas?

Sim. Contém a chave privada usada para assinar licenças e não é criptografado. Guarde-o em local controlado, com acesso restrito.

Posso atualizar da versão 0.1.3 ou 0.1.4?

A migração V8 é compatível com bancos dessas versões e preserva dados e chaves. Mesmo assim, faça backup antes de atualizar; licenças antigas podem precisar de emissão ou rotação do token.

Notas técnicas da versão 0.1.5
  • Aplicativo Electron para Windows x64, backend Java 25, Tomcat embutido e SQLite local.
  • Servidor local em porta dinâmica, validação de Host e proteção das operações administrativas.
  • Migração SQLite V8 aditiva, compatível com bancos 0.1.3/0.1.4; preserva dados e chaves existentes.
  • A versão 0.1.5 é pré-release candidata, sem homologação independente; Linux não faz parte desta entrega.

Visão Geral dos Projetos

O mesmo núcleo da capa: o que entregamos, o que já existe e o que ainda está em desenvolvimento — sem competir PDV, CSO e Hub com o restante do portfólio.

Os três produtos-chave são o CaraCore PDV (caixa no computador da loja), o CaraCore CSO (frota no navegador) e o CaraCore Hub (encomendas de Mercado Livre, Shopee e Temu).

O PDV tem duas linhas que convivem (nenhuma substitui a outra). O CSO de frota já está no ar; transportes no computador chegam em 08/Nov/2028. O Hub já tem vitrine; o instalador Windows, para instalar sem equipe de TI, está previsto para 06/Abr/2027.

1. CaraCore PDV — linha madura

Java 25 Quarkus JavaFX SQLite v3.2.2-free Oferta madura
Linha piloto do PDV (Windows, v0.1.2) — também desktop, convive com esta linha — seção 1b. Nenhuma substitui a outra.

O que muda para você

O CaraCore PDV Desktop é o sistema de caixa maduro da Cara Core: registrar vendas, receber PIX, emitir comprovantes e manter a operação estável. Disponível em Windows · Linux · macOS, com operação local, banco SQLite e evolução fiscal voltada a pequenos e médios negócios.

Posicionamento V3: produto direcionado a pequenos e médios negócios, com foco operacional no cenário de PIX Split 2027, para reduzir a complexidade da geração de notas e da conciliação no caixa.

Destaques:

  • PIX com QR Code e Split
  • Dashboard com gráficos (vendas, estoque, performance)
  • Multi-loja com estoque por unidade
  • Leitor de código de barras e atalhos de teclado
  • Relatórios em PDF (JasperReports)
  • Operação local com continuidade mesmo em cenário de contingência
  • Planos Free e Premium: Free — 100 vendas/mês, 10 SMS recibo/mês; Premium — recuperação de senha por SMS, relatório automático ao contador (e-mail), suporte prioritário (RustDesk/AnyDesk, Ajuda no layout). Liberação Premium somente após confirmação de pagamento e registro LGPD.

Detalhe opcional

O checkout Java trabalha com Java 25 + Quarkus + JavaFX + SQLite. Canal público atual: v3.2.2-free. O backend local cuida das APIs e integrações; a interface operacional fica na aplicação JavaFX.

Persona de negócio padronizada: gestor(a) de loja PME em crescimento, com equipe enxuta, pressão por fluxo de caixa e necessidade de simplificar rotina fiscal/financeira com transparência de evolução por versão.

Stack:

  • Backend local: Quarkus, JPA/Hibernate e integrações do domínio
  • Interface operacional: JavaFX para uso desktop
  • Testes: JUnit 5, Mockito, Selenium (Pytest), JaCoCo
  • Banco local: SQLite para operação soberana e primeiro acesso automatizado
Escopo: multi-plataforma (oferta madura) · Links: Portal oficial · Wiki do PDV
Portal oficial Loja online Wiki do PDV Hub PDV (duas linhas)

1b. CaraCore PDV — linha piloto

Rust Tauri 2 React SQLite v0.1.2 Piloto Windows

O que muda para você

Linha piloto do PDV no computador da loja: mais leve, em teste no Windows (release v0.1.2). Convive com a linha madura; não a substitui.

  • Checkout /vendas-v2, caixa, gestão, estoque e clientes (LGPD)
  • PDV local (um PC) ou na rede (vários caixas; PostgreSQL opcional)
  • Edição gratuita: até 100 vendas — condições na transparência da loja
  • Download oficial no GitHub Releases (NSIS, MSI pt-BR, ZIP + SHA256)

Detalhe opcional

Monorepo Rust + app Tauri 2 + UI React. Oficina caracore-pdv-rust; loja caracore-pdv-rust-releases em rust-pdv.caracore.com.br. Homologação SEFAZ real e multi-loja plena ainda não fazem parte do piloto.

Links: Loja Rust · Wiki da linha piloto · GitHub tag v0.1.2
Seu papel como estagiário: UI React/Tauri, contrato OpenAPI/Zod, smokes e copy honesta (nunca dizer que Rust substitui Java).

3. ETE Minerador 4.0 - Simulador para Ensino Médio

Python Streamlit ETE Terras Raras Ensino Médio

O que muda para você

O Minerador 4.0 é um simulador que aplica a lógica das Estações de Tratamento de Efluentes (ETE) ao refino de terras raras. No computador, o aluno ou o engenheiro explora cenários de separação mineral usando tanques em série, decantação e controle de pH — sem risco e com base em modelos validados.

Foco Ensino Médio Escolar:

  • Laboratório Campo Largo: rochas, Python e química para mentes jovens
  • Uso em sala de aula ou laboratório de informática
  • Material de apoio: apostila, manual em PDF, painéis interativos
  • Versão gratuita para uso educacional; upgrade Ouro 4.0 (R$ 29,90) opcional com liberação após confirmação de pagamento e registro LGPD

Detalhe opcional

Instalador Windows (.exe), checksums SHA-256 e MD5. Arquitetura ETE transferida para refino mineral; módulo Mineração desbloqueado via upgrade Ouro 4.0 (PIX + license.key), com liberação após confirmação de pagamento e registro LGPD.

4. Reino OIDC - Educação em Segurança

OAuth 2.1 OIDC Educação Licença Proprietária

O que muda para você

O Reino OIDC é como um "jogo educativo" que ensina sobre segurança na internet. Imagine aprender sobre senhas e logins através de uma história de fantasia com personagens divertidos!

O que ensina:

  • Como funcionam os logins "Entrar com Google"
  • Por que é mais seguro do que senhas tradicionais
  • Como os apps pedem permissão para seus dados
  • Conceitos de segurança digital de forma divertida
Projeto proprietário: gratuito para pessoas físicas (uso pessoal e estudo). Upgrade Premium liberado somente após confirmação de pagamento e registro LGPD.

Detalhe opcional

Plataforma educacional gamificada que ensina OAuth 2.1 e OpenID Connect através de narrativa épica, flashcards interativos e progressão por níveis.

Recursos técnicos:

  • 60 flashcards interativos em 3 níveis
  • Sistema de progressão e badges
  • Diagramas técnicos Mermaid.js
  • Narrativa gamificada
  • Documentação dual (leigos/experts)
  • Deployment em canal institucional
Seu papel como estagiário: Criar novos flashcards, melhorar UX/UI, traduzir conteúdo, adicionar animações.

5. Cara Core Seed - Contador de Licenças

Windows Desktop Electron SQLite Java

O que muda para você

O Cara Core Seed é o Contador de Licenças para quem compra os produtos Cara Core (PDV, Minerador 4.0, Reino OIDC, Hub) para rodar no Windows. Foco localhost e Windows Desktop: o aplicativo roda no computador do cliente; ao abrir, sobe em localhost e abre a interface. SQLite local, 100% offline. O produto existe, mas a aplicação não está em oferta ativa no momento.

Vantagens:

  • Portal de controle com transparência e LGPD
  • EXE para Windows (Electron + servidor local)
  • Banco apenas SQLite no escopo
  • Licença atrelada ao hardware (license.key)

Detalhe opcional

WAR Java com SQLite local; Electron inicia JRE + WAR e abre em http://localhost:9080. Dois perfis: Contador de Clientes (uso interno) e Comprador (consulta). Testes com foco em localhost e Desktop Electron (UT, HTTP, E2E).

Escopo:

  • localhost + Windows Desktop (Electron)
  • SQLite como único banco no escopo
  • Build EXE e publicar em caracore-seed-releases
Links: Portal Seed · Repositório de releases (referência): https://github.com/chmulato/caracore-seed-releases/releases

7. Cara Core Hub - Gestão de Encomendas

Jakarta EE 10 WAR / Tomcat Marketplaces Bunker GA instalador — 06/Abr/2027
Garagem no calendário oficial refere-se ao instalador Windows (06/Abr/2027). A vitrine já está em hub.caracore.com.br. A oficina já tem a aplicação web 2.1 (WAR/Tomcat); isso ainda não é oferta madura nem SaaS público.

O que muda para você

Quem vende em vários marketplaces (Mercado Livre, Shopee, Temu) costuma abrir vários painéis para ver o mesmo tipo de pedido. O Hub junta pedidos, estoque e retirada num só lugar — para o centro de distribuição, não para “ligar os produtos da Cara Core entre si”.

Benefícios práticos:

  • Pedidos de vários canais numa fila só
  • Mapa de estoque e conferência na retirada
  • Aviso quando um volume atrasa
  • Dados no computador do cliente no lançamento Windows (Bunker)

Detalhe opcional

Oficina caracore-hub (privada): Jakarta EE 10, WAR/Tomcat, JSP, PostgreSQL e Redis na aplicação web atual. Destino público: instalador Windows com SQLite. Tia Sócia é exemplo de negócio na loja, não o nome do produto.

Arquitetura:

  • Aplicação Java empacotada como WAR (Tomcat 10.1)
  • Conectores: Mercado Livre, Shopee, Temu
  • RBAC ADMIN / SUPERVISOR / OPERADOR
  • Licença proprietária; CTA público = hub.caracore.com.br
Loja: hub.caracore.com.br — vitrine e artefatos de pré-lançamento; GA do instalador em Abr/2027.
Seu papel como estagiário: Ler STATUS-ATUAL da oficina. Não descrever o Hub como Python/Flask nem como orquestrador interno da Cara Core.

9. Helianto Condominium — Administração Condominial

Java 25 Spring Boot 4 React PostgreSQL JasperReports Garagem — Dez/2027

O que muda para você

O Helianto Condominium é a central do morador e do síndico para organizar a rotina do condomínio. Ele controla a entrada/saída de moradores, faz o rateio das despesas mensais de forma justa e gera o boleto contendo o QR Code Pix de liquidação imediata (BolePix) com total conformidade e privacidade.

Destaques:

  • Acesso a boletos e cópia da linha digitável no celular
  • Gestão de moradores e vínculo a unidades
  • Baixa automática e manual de pagamentos
  • Rateio por fração ideal, valor fixo ou igualitário
  • Histórico de consentimento LGPD integrado

Detalhe opcional

Arquitetura moderna de multilocação (multi-tenant) com shared schema PostgreSQL e isolamento robusto via tenant_id e ThreadLocal.

Stack:

  • Backend: Spring Boot 4.0.6, Java 25 LTS, Spring Data JPA
  • Frontend: React + Vite + TypeScript responsivo (abstração por persona)
  • Relatórios: PDF via JasperReports e QR Code Pix EMV integrado
  • Segurança: RBAC (ADMIN, SYNDIC, USER) e sanitização LGPD via PrivacyGuard (LGPD Shield)
Escopo: Monorepo corporativo · Loja: helianto.caracore.com.br
Seu papel como estagiário: Desenvolver endpoints de relatórios adicionais, ajudar na cobertura de testes integrados do motor financeiro e auxiliar na interface React de visualização de consumo.

10. CaraCore CSO — Frotas e Transportes

Quarkus Java 21 PostgreSQL Qute / HTMX JavaFX SQLite Frotas em produção Transportes 08/11/2028
Duas frentes, um produto: a Gestão de Frotas já está no ar; a Gestão de Transportes é o bunker desktop de 2028. O CSO de gestão não inclui rastreador GPS nem mapa ao vivo (Virtual Tracker™ é produto separado).

O que muda para você

O CaraCore CSO tira a frota da planilha. No navegador, a empresa cadastra veículos, combustível, manutenções, motoristas e viagens, com relatórios e conformidade LGPD. Começa grátis com até 3 veículos. O desktop de 2028 guarda a operação crítica no computador da empresa — mesmo se a internet falhar.

Destaques da Frotas (já disponível):

  • Planos FREE_3 (R$ 0), P5 (R$ 5/mês), P10 (R$ 10/mês) e CORPORATE (R$ 49/mês, até 50 veículos)
  • Perfis ADMIN, GESTOR e ENTREGADOR no mesmo login
  • Pix avulso no Brasil e transferência internacional equivalente em R$
  • Relatórios de consumo, manutenção, status da frota, CNH e viagens

Detalhe opcional

Não há oficina única caracore-cso. A URL canónica é a aplicação, não GitHub Pages.

  • Frotas: caracore-cso-quarkus — Java 21, Quarkus, PostgreSQL 16, Qute/HTMX, sessão opaca, multi-tenant
  • Transportes: caracore-cso-transportes — Quarkus + SQLite, SPA Vue 3 e cliente JavaFX (bunker offline)
  • i18n da Frotas: pt / en / es / it / de
Aplicação: cso.caracore.com.br · Wiki: hub CSO
Seu papel como estagiário: na Frotas, telas Qute/HTMX, i18n e relatórios; no Transportes, JavaFX/Vue e persistência SQLite — sempre sem vender GPS na copy.

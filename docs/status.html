Estado dos Produtos

O que está no ar, o que está em pré-lançamento e o que está previsto. A página inicial explica o que cada produto faz; esta página registra versões, datas e o que ainda depende de validação.

Quadro consolidado em 31/10/2026. Detalhes de release ficam na loja de cada produto.

Como ler os rótulos: indicado para operar não significa “mais recente”; pré-lançamento e RC são versões para avaliação, não GA; GA é a disponibilidade geral do instalador homologado; uma data-alvo não confirma disponibilidade.
